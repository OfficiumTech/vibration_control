about=English: GIS plugin for QGIS to simulate blast-induced vibrations, assist in rock blasting safety, plot PPV (Peak Particle Velocity) isolines, and calculate maximum explosive charge per hole or delay for critical distances. Before using, you need to install the pykrige library using the OSGeo4W Shell. Run: pip install pykrige and pip install --upgrade openpyxl. Note: To ensure proper functioning, use a Cartesian coordinate system such as UTM (Universal Transverse Mercator).
 Portuguese: Ferramenta GIS para o QGIS, capaz de simular vibrações, auxiliar na segurança de desmontes de rocha, plotar isolinhas de PPV (Velocidade Pico de Partícula) e calcular a carga máxima de explosivo por furo ou retardo conforme distâncias de estruturas críticas. Antes de usar, é necessário instalar a biblioteca pykrige no prompt OSGeo4W Shell. Execute: pip install pykrige e pip install --upgrade openpyxl. Observação: Para garantir o funcionamento adequado, utilize um sistema de coordenadas cartesianas, como projeções UTM (Universal Transverse Mercator).
