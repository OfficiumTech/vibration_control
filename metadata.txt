about=English: GIS plugin for QGIS to simulate blast-induced vibrations, assist in rock blasting safety, plot PPV (Peak Particle Velocity) isolines, and calculate maximum explosive charge per hole or delay for critical distances. Before using, you need to install the pykrige and openpyxl library using the OSGeo4W Shell. Run: pip install pykrige and pip install --upgrade openpyxl. Note: 1) - To ensure proper functioning, use a Cartesian coordinate system such as UTM (Universal Transverse Mercator). 2) - Demonstration vídeo: "https://www.youtube.com/watch?v=ECgg6inDFh4" 3) - For more features, please contact by email or Linkedin: "www.linkedin.com/in/bruno-soares-mosso-535562325".
 Portuguese: Ferramenta GIS para o QGIS, capaz de simular vibrações, auxiliar na segurança de desmontes de rocha, plotar isolinhas de PPV (Velocidade Pico de Partícula) e calcular a carga máxima de explosivo por furo ou retardo conforme distâncias de estruturas críticas. Antes de usar, é necessário instalar a biblioteca pykrige e openpyxl no prompt OSGeo4W Shell. Execute: pip install pykrige e pip install --upgrade openpyxl.
